#  MovieHub

A React movie discovery app for browsing trending films and TV shows, searching by title, and exploring detailed pages for both titles and cast members.

##  Features
- **Home page** — animated poster wall backdrop with a search bar and a trending titles carousel.
- **Search** — find movies and TV shows by name.
- **Movie / TV details** — poster, synopsis, rating, age certification, runtime, genres, cast, and trailer playback.
- **Person details** — biography, birthdate, known roles, IMDB link, and full filmography.
- **Favorites** — save titles to a personal list, persisted in localStorage.

##  Tech Stack
- **Framework:** React 19 (with the React Compiler enabled)
- **Build Tool:** Vite 7 for bundling and dev server
- **Routing:** React Router 7 for client-side routing
- **API:** TMDB API for movie, TV, and person data
- **Icons:** `react-icons` for UI icons
